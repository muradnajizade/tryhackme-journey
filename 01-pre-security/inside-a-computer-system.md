# Inside a Computer System

**Platform:** TryHackMe
**Path:** Pre Security → Computer Fundamentals

## Nə etdim
3D laboratoriyada kompüteri hissə-hissə yığdım (PSU, CPU, RAM, disk və s.).

## Nə öyrəndim
- **PSU (Power Supply Unit):** divardan gələn elektriki hər komponent üçün lazım olan gərginliyə çevirir. Korpusun kənarında yerləşir.
- Labda bir hissə "başqa maşın üçün" idi. Uyğun gəlməyən hissəni tapıb çıxarmaq lazım idi.

## Blue Team baxışı
Hissələri tanımaq fiziki hücumları başa düşmək üçün vacibdir. Məsələn **Cold Boot attack**-da kompüter söndürüldükdən sonra RAM-da qalan məlumatlar (şifrə açarları) oxunur.
Normal mənzərədə "yad" olanı tapmaq SOC işinin özüdür.
